# Fake News Detector

A machine learning-based web application that detects whether a given news article is Fake or Real using Natural Language Processing (NLP) and text classification techniques.

---

## Features
- Detects fake and real news from text input
- NLP-based text preprocessing
- Machine learning classification
- Simple and user-friendly interface
- Fast prediction results

---

## Tech Stack
- Python
- Machine Learning
- NLP
- Scikit-learn
- Pandas & NumPy
- Flask
- React JS

---

## How It Works
1. User enters a news headline or article.
2. The text is cleaned and preprocessed using NLP techniques.
3. The trained machine learning model analyzes the text.
4. The model predicts whether the news is Fake or Real.
5. The prediction is displayed to the user.
